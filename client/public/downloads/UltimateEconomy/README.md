# UltimateEconomy & Vault System v2.4.0
Official verified resource from **MinoForge** (colasmp.net).

## Installation
1. Place `UltimateEconomy.jar` into your Minecraft server's `/plugins` directory.
2. Ensure you have `Vault` installed if you want other plugins to tap into your economy.
3. Restart your server to generate the default configuration.
4. Customize `config.yml` with your preferred currency names and database settings.

## Commands
* `/balance [player]` - Check your wallet balance (`mino.eco.balance`)
* `/pay <player> <amount>` - Send coins to an online player (`mino.eco.pay`)
* `/bank open` - Open interactive ATM banking GUI with PIN protection (`mino.bank.use`)
* `/eco give/take/set <player> <amount>` - Administrator economy control (`mino.eco.admin`)

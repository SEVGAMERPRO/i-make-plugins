# Discord Ticket & Transcripts Bot v1.0.0
Official verified resource from **MinoForge** (colasmp.net).

## Features
* 1-Click Interactive Button support
* Modal reason popup
* HTML Transcripts exported on ticket close
* Role-based permissions

## Quick Start
1. Install dependencies:
   ```bash
   npm install
   ```
2. Set your Discord bot token in `config.json` or `.env`.
3. Start the bot:
   ```bash
   node index.js
   ```

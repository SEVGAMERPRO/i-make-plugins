
1. **Discovery:** Browse the master catalog at `/plugins` or game hubs like `/games/minecraft`. Inspect screenshots, video demos, commands, and verified buyer reviews.
2. **Instant Purchase:** Click "Buy Now" or "Add to Cart" and complete payment via PayPal. Transactions are cryptographically secured and processed in real time.

2. **Package Your Plugin:** Prepare a `.zip` archive containing your binary (`.jar` or script), a clean `config.yml`, setup documentation, and a `manifest.json`:

### 🔬 Server Crash Analyzer (`/crash-analyzer`)
Paste raw console error dumps to receive instant root-cause analysis:
1. **The NullPointerException (NPE) in Event Listeners:**
   - Stack signature: `java.lang.NullPointerException: Cannot invoke Player.getItemInHand() because player is null`
   - Diagnosis: Plugin is calling legacy API methods removed in Paper 1.20.4.
   - Remedy: Recompile against modern Paper API or update to the latest plugin build.
2. **The ClassNotFoundException Missing Dependency:**
   - Stack signature: `java.lang.NoClassDefFoundError: net/milkbowl/vault/economy/Economy`
   - Diagnosis: The plugin requires Vault and a compatible economy provider plugin.
   - Remedy: Install Vault.jar and an economy provider such as EssentialsX.
3. **The OutOfMemoryError (OOM) Heap Failure:**
   - Stack signature: `java.lang.OutOfMemoryError: Java heap space`
   - Diagnosis: Server memory limit exceeded or memory leak in chunk loading.
   - Remedy: Apply Aikar flags (`-XX:+UseG1GC -XX:G1ReservePercent=20`) and reduce simulation distance to 6.
4. **The ConcurrentModificationException Asynchronous Crash:**
   - Stack signature: `java.util.ConcurrentModificationException at java.util.ArrayList$Itr.checkForComodification`
   - Diagnosis: An entity or world collection was modified asynchronously outside the main server thread.
   - Remedy: Wrap the operation in `Bukkit.getScheduler().runTask(plugin, ...)` to ensure main thread execution.
5. **The FiveM Script Execution Timeout Crash:**
   - Stack signature: `SCRIPT ERROR: execution timed out after 50000 ticks in scheduler.lua`
   - Diagnosis: An unthrottled `while true do` loop ran without a `Citizen.Wait(0)` yield statement.
   - Remedy: Ensure every infinite polling loop includes a non-blocking `Wait(100)` or event-driven hook.
6. **The Discord.js Missing Permissions Crash (Error 50013):**
   - Stack signature: `DiscordAPIError[50013]: Missing Permissions at handleErrors`
   - Diagnosis: Bot role is ranked lower in the guild hierarchy than the member or channel it attempted to modify.
   - Remedy: Move the bot's role above the target member roles in Server Settings -> Roles.

- **Asynchronous Task Rules:** Never manipulate Bukkit world state, blocks, or player inventories outside the primary server thread. Use `BukkitRunnable` or asynchronous scheduling for database and network tasks.
- **Folia Regionized Threading:** Support Folia multi-threading by leveraging Paper region schedulers rather than legacy global tickers.

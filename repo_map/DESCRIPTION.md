# MiniForge Plug‑in Marketplace Overview

**MiniForge** (https://minoforge.com) is a community‑driven marketplace where developers and designers can discover, purchase, and integrate plug‑ins that extend the functionality of the MiniForge platform. This repository contains the full source code for the live site, as well as a clean GitHub‑ready package in `repo_map` for external developers.

The platform enables:
- Browsing and searching a rich catalog of plug‑ins.
- One‑click purchase and licensing via PayPal.
- Installation through manual download or API‑driven deployment.
- Ratings, reviews, and a developer dashboard for managing plug‑ins.
- Internationalisation and a responsive UI.
